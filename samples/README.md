# 예시 데이터

전래동화 인물로 꾸민 결혼식 · 장례식 예시입니다. 앱 코드에는 아무것도 넣지 않았고, 데이터는 전부 이 폴더의 파일에만 있습니다.

| 파일 | 용도 |
|---|---|
| `sample-data.json` | 사람이 읽고 고치는 원본 |
| `예시데이터.enote` | 앱에 바로 넣는 파일 (`sample-data.json` 에서 구움) |

## 넣는 방법

앱에서 **파일 → 데이터 가져오기(.enote)** 를 고르고 `예시데이터.enote` 를 엽니다.

가져올 때 세 가지를 묻습니다.

- **예** — 지금 목록에 합칩니다. 원래 쓰던 행사는 그대로 남습니다.
- **아니오** — 지금 목록을 지우고 예시로 바꿉니다.
- **취소** — 아무것도 하지 않습니다.

예시만 구경하고 지울 거라면 미리 **파일 → 데이터 내보내기** 로 현재 데이터를 백업해 두는 편이 안전합니다.

## 들어 있는 내용

| 행사 | 인원 | 금액 | 식권 | 식대 차감 후 |
|---|---:|---:|---:|---:|
| 💍 이몽룡 ♥ 성춘향 결혼식 (남원 광한루원) | 16명 | 2,020,000원 | 30장 | 760,000원 |
| 🕯 故 곽씨 부인 상 (황주 도화동) | 12명 | 1,290,000원 | 안 씀 | — |

관계(분류)는 가족 · 친척 · 신랑측 · 신부측 · 친구 · 직장 · 학교 · 단체 · 이웃 · 기타를 골고루 씁니다. 분류별 집계와 식대 차감 계산을 한눈에 확인하려는 목적입니다.

장례식 쪽은 `UsesMealTickets` 를 꺼 두었습니다. 두 행사를 번갈아 눌러 보면 식권 열 · 식권합계 열 · 식권 타일 · 식대 차감 타일이 나타났다 사라지는 것을 볼 수 있습니다.

## 고치고 다시 굽기

`sample-data.json` 을 고친 뒤:

```bash
dotnet run --project tools/SampleDataBuilder
```

`samples/예시데이터.enote` 가 다시 만들어집니다. 구운 직후 앱과 같은 경로로 되읽어 검증하므로, 통과 메시지가 나오면 앱에서도 열립니다.

다른 파일로 넣고 빼려면 경로를 직접 줍니다.

```bash
dotnet run --project tools/SampleDataBuilder -- 입력.json 출력.enote
```

### JSON 규칙

- 속성 이름은 대문자로 시작합니다 (`Title`, `Guests` …). 앱 모델 이름 그대로라 대소문자를 가립니다.
- `Category` 는 이름으로 적습니다 — `Wedding` `Funeral` `FirstBirthday` `SixtiethBirthday` `SeventiethBirthday` `EightiethBirthday` `Opening` `Etc`.
- `Id` · `CreatedAt` · `ModifiedAt` 은 적지 않아도 됩니다. 구울 때 새로 붙습니다.
- `UsesMealTickets` 는 식권을 쓰는 행사인지입니다. 적지 않으면 `true`. `false` 면 식권 · 식대 관련 항목이 화면과 엑셀에서 모두 빠집니다.
- `MealPrice` 는 식권 1장 단가입니다. 집계의 "총 (식대 차감)" 에 쓰입니다. `UsesMealTickets` 가 `false` 면 쓰이지 않습니다.

`tools/SampleDataBuilder` 는 `EventNote.sln` 에 넣지 않았습니다. 앱 빌드와 무관하게 필요할 때만 돌아갑니다.
